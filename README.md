                                          BOAS PRATICAS

A seguir, apresentamos algumas práticas que podem ser utilizadas para promover a inclusão de boas condutas para melhorar o trabalho em equipe.

1.  **Definir objetivos claros**: É importante estabelecer objetivos
2.  **Comunicação aberta**: Fomentar uma cultura de comunicação aberta e honesta entre
3.  **Documentar**: Documentar todos os ocorridos 
4.  **Proteger**: Proteger todos os registros do cliente
5.  **Revisar**: Revisar toda a documentação e codificação do projeto
6.  **Pesquisa**: Documentar e salvar todos os métodos de pesquisa.
7.  **Modelo Explicável e Transparente**: Desenvolva um modelo que possa explicar suas decisões de forma compreensível para os profissionais de saúde, facilitando a confiança.
